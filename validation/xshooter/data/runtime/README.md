# Runtime regression data

`zshooter_blue20_swath.npz` and `xshooter_uvb20_swath.npz` contain the keyword arguments received by `pyreduce.extraction_uncertainty.slit_response` at the saved 20-day failures. They preserve the image, final rejection mask, trace/slit geometry, starting profile, oversampling and regularization settings. The source frames are the current `SPEC` ZShooter and faint-mode X-shooter runs in the two kilonova notebooks. These small swaths are solver inputs, not substitute detector frames.

`faint_swath_convergence.csv` compares native iteration allowances with the repaired uncertainty refinement. Full-arm reduction timings come from the actual saved stochastic frames and existing calibration files; they include extraction, covariance and flux calibration. They are not optical-observation benchmarks.

`initial_saved_errors.csv` records the five original notebook exceptions. The final notebook inventory and remaining-error files are generated by `Notebook_Runtime_Checks.ipynb`. A syntax/saved-output audit is distinguished from actual execution in the [runtime report](../../../../docs/notebook-runtime-checks.md).
